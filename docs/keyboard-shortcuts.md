# Keyboard shortcuts

Workbench follows CLion's keymap where CLion has the action. A terminal keeps every key
typed into it (Ctrl+T, Ctrl+K and Ctrl+P mean something to your shell and to Claude
Code), and keys the focused editor uses stay with the editor. Settings › General switches
the editor's editing keys to VS Code's.

## Everywhere

| Key | Action |
| --- | --- |
| Double Shift | Search Everywhere: files, symbols, text, actions |
| Ctrl+K, Ctrl+Shift+P | Command palette (Ctrl+Shift+P works inside terminals too) |
| Ctrl+P | Go to File |
| Ctrl+Shift+F | Find in Files |
| Ctrl+E / Ctrl+Shift+E | Recent Files (again: changed files only) / Recent Locations |
| Ctrl+Alt+Left / Right, Alt+Left / Right | Navigate back / forward |
| Ctrl+, | Settings |
| Ctrl+Shift+A | New agent session (in the editor: Ask Agent About Selection) |
| Ctrl+Alt+Shift+Insert | New Scratch File |
| Alt+F1 | Reveal the active file in the project tree |
| Alt+Shift+C | Recent Changes (Local History) |

## Editor

| Key | Action |
| --- | --- |
| Ctrl+S | Save |
| Ctrl+B, Ctrl+click | Go to Declaration or Usages |
| Ctrl+Alt+B / Ctrl+Shift+B | Go to Implementation / Type Declaration |
| Alt+F7 / Ctrl+Alt+F7 | Find Usages / Show Usages |
| Ctrl+Alt+H / Ctrl+H | Call Hierarchy / Type Hierarchy |
| Shift+F6 | Rename |
| Alt+Enter | Show Context Actions |
| Ctrl+Alt+L | Reformat Code |
| Ctrl+F12 | File Structure |
| F2 / Shift+F2 | Next / Previous Highlighted Error |
| Ctrl+Alt+Shift+N | Go to Symbol |
| Ctrl+D / Ctrl+Y | Duplicate line / Delete line |
| Ctrl+Shift+Up / Down | Move line up / down |
| Alt+J / Alt+Shift+J | Select next occurrence / Unselect |
| Ctrl+Shift+U | Toggle case |
| Ctrl+Q | Quick documentation |
| F11 / Ctrl+F11 / Shift+F11 | Toggle bookmark / with a mnemonic / Show bookmarks |
| Alt+Shift+Insert | Column Selection Mode |
| Ctrl+Enter | Send the request (`.http` files); run the statement (SQL console) |

## Debugger

| Key | Action |
| --- | --- |
| Shift+F9 / Alt+Shift+F9 | Debug / Debug… (pick a configuration) |
| Ctrl+F8 | Toggle line breakpoint |
| F8 / F7 / Shift+F8 | Step Over / Into / Out (while a session is live) |
| F9 | Resume |
| Alt+F9 | Run to Cursor |
| Ctrl+F2 | Stop |

## Version control

| Key | Action |
| --- | --- |
| Alt+0 | Commit |
| Ctrl+T | Update Project |
| Ctrl+Shift+K | Push |
| F7 / Shift+F7 | Next / Previous Difference (in a diff) |
| Ctrl+Alt+Z | Revert selected lines (Local History diff) |
